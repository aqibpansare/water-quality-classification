# Autonomous Execution Guidelines

1. **Autonomous Action**: Proceed automatically with file edits, code implementation, running commands, and testing without pausing to ask the user "yes/no" or permission confirmation.
2. **Make Reasonable Decisions**: When multiple standard options exist, select the best practice approach and implement it directly rather than asking trivial multiple-choice questions.
3. **Execution Over Confirmation**: Focus on running commands, verifying output, and solving problems end-to-end. Report outcomes and changes clearly.
